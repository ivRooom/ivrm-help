このページでは、IVRMのMinecraft生活鯖へ参加するための基本手順を説明します。

:::note[現在の公開情報]
サーバーアドレス、配布ファイル、ホワイトリスト申請先はDiscord内の最新案内を確認してください。この公開ページには、セキュリティ上掲載すべきでない接続情報を直接記載しません。
:::

## 参加前に必要なもの

- Minecraft Java Editionを利用できるMicrosoftアカウント
- IVRM Discordへの参加
- Discordで案内されている対応ランチャー
- Modpackを動かせるPC環境

## 参加手順

### 1. IVRM Discordへ参加する

[Discordへの参加](/getting-started/discord/)を確認し、コミュニティへ参加します。

### 2. ルールを確認する

参加前に[コミュニティルール](/minecraft/rules/)を読み、禁止事項を確認します。

### 3. Minecraft IDを申請する

Discord内の指定された場所でMinecraft IDを申請します。ホワイトリスト登録が完了するまで接続できません。

### 4. 指定ランチャーを準備する

ゲームモードによって利用するランチャーが異なります。

| ゲームモード | 基本ランチャー |
| --- | --- |
| Main生活鯖 | CurseForge |
| ATM10 | CurseForge |
| GTNH | Prism Launcher |
| Hardcore | 任意の対応ランチャー |

### 5. 配布されたプロファイルを導入する

Discordで案内されているプロファイルまたはModpackをインポートします。MODを個別に追加・削除すると接続できなくなる場合があります。

### 6. メモリを設定する

大型Modpackでは十分なメモリが必要です。PC全体のメモリを使い切らない範囲で、Discordの案内に従って割り当てます。

### 7. サーバーを登録して接続する

Discordに掲載されている最新のサーバーアドレスを、Minecraftのマルチプレイ画面へ登録します。

### 8. 初回参加後の確認

- チャットや案内表示を確認する
- 他人の建築やアイテムに触れる前にルールを確認する
- 不明点はMinecraftサポート用チャンネルで質問する
