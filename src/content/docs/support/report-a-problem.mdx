---
title: 問題を報告する
description: 問い合わせをスムーズに進めるための報告方法
---

問題を報告するときは、再現や調査に必要な情報をまとめてください。

## 報告テンプレート

```text
【対象サービス】Minecraft / Discord / Web / その他
【ゲームモード】Main / ATM10 / GTNH / Hardcore / 該当なし
【発生日時】YYYY-MM-DD HH:mmごろ
【発生したこと】
【直前に行った操作】
【再現するか】毎回 / ときどき / 1回のみ
【エラーメッセージ】
【添付】スクリーンショット、latest.log、クラッシュレポート
```

## 添付してはいけない情報

- パスワード
- アクセストークン
- 個人情報
- 他人の非公開情報
- 公開が許可されていないサーバー情報

:::tip
長いログはチャットへ全文貼り付けず、Discordで指定された方法に従ってファイルとして添付してください。
:::
