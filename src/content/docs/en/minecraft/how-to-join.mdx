This page explains the basic steps for joining the IVRM Minecraft server.

:::note[Currently published information]
Check the latest Discord announcement for the server address, distributed files, and whitelist application location. Connection information that should not be publicly disclosed is not listed on this website.
:::

## What you need

- A Microsoft account that can use Minecraft Java Edition
- Membership in the IVRM Discord server
- The launcher specified in Discord
- A PC capable of running the Modpack

## Steps

### 1. Join IVRM Discord

Follow [Join Discord](../../getting-started/discord/) to enter the community.

### 2. Review the rules

Read the [Community Rules](../rules/) and check the prohibited activities before joining.

### 3. Submit your Minecraft ID

Submit your Minecraft ID in the designated Discord channel. You cannot connect until whitelist registration is complete.

### 4. Install the specified launcher

The launcher depends on the game mode.

| Game mode | Primary launcher |
| --- | --- |
| Main server | CurseForge |
| ATM10 | CurseForge |
| GTNH | Prism Launcher |
| Hardcore | Any supported launcher |

### 5. Import the distributed profile

Import the profile or Modpack announced in Discord. Adding or removing individual mods may prevent you from connecting.

### 6. Configure memory

Large Modpacks require enough memory. Follow the Discord guidance while leaving enough memory for the rest of your PC.

### 7. Register and connect to the server

Add the latest server address from Discord to the Minecraft multiplayer screen.

### 8. Check after your first connection

- Review chat messages and on-screen guidance
- Check the rules before interacting with another player’s buildings or items
- Ask questions in the Minecraft support channel
