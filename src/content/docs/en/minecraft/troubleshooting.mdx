---
title: Minecraft Troubleshooting
description: Checks for connection, startup, and performance problems
---

## Cannot connect to the server

Check the following in order:

1. Review Discord for outage or maintenance information.
2. Confirm that the server address is current.
3. Confirm that whitelist registration is complete.
4. Check the Minecraft and Modpack versions.
5. Sign in to your Microsoft account again.

## A mod mismatch is displayed

- Reimport the distributed profile.
- Check whether you added or removed any mods.
- Confirm that you are not launching an old profile.
- Check Discord for update announcements.

## The game crashes during startup

- Confirm that you are using the supported Java version.
- Check whether the allocated memory is too low.
- Check available system memory and storage.
- Temporarily remove shaders and additional resource packs.
- Save the crash report.

## Performance is poor

1. Lower the render and simulation distances.
2. Disable shaders.
3. Set an FPS limit.
4. Close background applications.
5. Check the recommended memory settings.

## Information needed for support

- Game mode
- Minecraft version
- Launcher name
- Date and time of the issue
- Error message
- `latest.log` or crash report
- Action performed immediately before the issue

When the problem remains unresolved, use the template on [Report a Problem](/en/support/report-a-problem/).
