## Can I join from Minecraft Bedrock Edition?

The currently documented Modpack environments are designed for Java Edition. Check the latest information for each game mode to confirm eligibility.

## Where can I find the server address?

Check the Minecraft information in IVRM Discord. Private connection information is not published on this website.

## Can I add mods myself?

Changing the distributed profile may cause your configuration to differ from the server, so use the profile without modification unless instructed otherwise.

## I found a rule violation

Do not confront the person in a public channel. Report the situation and supporting evidence to the administrators.
