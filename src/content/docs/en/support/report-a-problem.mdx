---
title: Report a Problem
description: Information that helps support investigate an issue
---

When reporting a problem, include the information needed to reproduce and investigate it.

## Report template

```text
[Service] Minecraft / Discord / Web / Other
[Game mode] Main / ATM10 / GTNH / Hardcore / Not applicable
[Date and time] Around YYYY-MM-DD HH:mm
[What happened]
[Action immediately before the issue]
[Reproducibility] Every time / Sometimes / Once
[Error message]
[Attachments] Screenshot, latest.log, crash report
```

## Do not attach

- Passwords
- Access tokens
- Personal information
- Another person’s private information
- Server information that is not approved for public disclosure

:::tip
Do not paste a full long log into chat. Attach it as a file using the method specified in Discord.
:::
