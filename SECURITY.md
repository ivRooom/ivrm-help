# Security Policy

## Supported version

The `main` branch is the only supported version of IVRM Help Center.

## Reporting a vulnerability

Do not post secrets, personal information, private server details, access URLs, internal addresses, or reproducible attack details in a public issue.

Use GitHub's **Security** tab and submit a private vulnerability report. For documentation mistakes that do not involve sensitive information, use the public issue template.

## Public repository policy

This repository contains only resources required to build and publish the public Help Center. Internal infrastructure notes, credentials, incident logs, private endpoints, and operational runbooks are managed outside this repository.
